# A Hayley Original — Custom Shopify Theme

A custom Shopify theme built from scratch for 
[ahayleyoriginal.com](https://ahayleyoriginal.com) — a live e-commerce store. 
Developed using Shopify's theme architecture with Liquid, JavaScript, and CSS.

---

## Tech Stack

- **Liquid** — Shopify's templating language
- **JavaScript**
- **HTML & CSS**
- **Shopify CLI**

---

## Theme Architecture

| Folder | Purpose |
|--------|---------|
| `assets` | CSS, JS, images and fonts |
| `layout` | Top-level page wrappers |
| `locales` | Translation files |
| `sections` | Modular full-width page components |
| `snippets` | Reusable Liquid code fragments |

---

## Key Sections Built

| File | Purpose |
|------|---------|
| `hero.liquid` | Homepage hero banner |
| `featured-products.liquid` | Product highlights grid |
| `product.liquid` | Full product detail page |
| `collection.liquid` | Product collection/category pages |
| `cart.liquid` | Shopping cart |
| `header.liquid` | Site-wide navigation header |
| `footer.liquid` | Site-wide footer |
| `search.liquid` | Search results page |
| `info-tabs.liquid` | Custom tabbed content section |
| `announcement-bar.liquid` | Top-of-page announcement banner |

---

## Features

- Fully custom theme built from scratch (not a modified template)
- Schema-driven sections and blocks for merchant customisation
- Integrated AI-powered product recommendations
- SMS marketing app integration
- Optimised for mobile-first browsing
- Multi-channel sales: TikTok, Google, Instagram, X

---

## Getting Started

### Prerequisites

- [Shopify CLI](https://shopify.dev/docs/themes/tools/cli) installed
- A Shopify store or development store

### Preview Locally
```bash
shopify theme dev
```

### Push to Store
```bash
shopify theme push
```
